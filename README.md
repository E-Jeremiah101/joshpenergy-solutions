# Sunvolt Energy landing page

A responsive single-page React site built with Vite.

## Run locally

```sh
npm install
npm run dev
```

Create and preview a production build with `npm run build` and `npm run preview`.

## Make it yours

- Edit the `projects` and `services` arrays near the top of `src/App.jsx` to change project cards, descriptions, and service details.
- Update the About section, name, service area, phone number, and email in `src/App.jsx`. The current identity and contact details are sample content; replace them before publishing.
- Replace the Unsplash image URLs in `src/App.jsx` with the client’s own project photography.
- Adjust the palette, typography, spacing, and responsive breakpoints in `src/styles.css`. The main colors are defined as CSS variables at the top of that file.
- The enquiry form uses a `mailto:` action, so it opens the visitor’s email app; connect a form service or backend if enquiries should be submitted directly on the website.
